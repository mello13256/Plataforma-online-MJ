# Pasta dos jogos

Coloca aqui cada jogo, exportado para HTML5/Web:

- **uma pasta** com os ficheiros do jogo (tem de ter um `index.html`), ou
- **um ficheiro `.zip`** com esses ficheiros (é extraído automaticamente).

Se puseres um `capa.png` (ou `.jpg`/`.webp`) dentro do jogo, fica disponível como capa.

No GitHub: abre esta pasta → **Add file → Upload files** → arrasta a pasta ou o `.zip` → **Commit changes**.
Passados 1 a 3 minutos o site é republicado e o jogo aparece no painel em **Publicar novo jogo**.

O nome da pasta ou do `.zip` passa a fazer parte do endereço (ex.: `Meu Jogo.zip` → `/jogos/meu-jogo/`).
